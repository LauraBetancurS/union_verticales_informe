# Tendencias 2026: unión de verticales

Informe interactivo que integra los radares trimestrales Q3 2026 de InnLab (Business Model Innovation, Fintech y Agrotech) en seis megatendencias, un mapa de escenarios cruzados y una agenda de acción.

- Archivo único y autocontenido: `index.html` (ilustraciones y logos embebidos).
- Identidad: manual de marca Universidad Icesi (kit Futuros Vivos), tipografía Plus Jakarta Sans.
- Para verlo, abre `index.html` en el navegador o activa GitHub Pages sobre la rama `main`.

Fuentes: Radares Trimestrales BMI, Fintech y Agrotech, Q3 2026. InnLab, Universidad Icesi.
